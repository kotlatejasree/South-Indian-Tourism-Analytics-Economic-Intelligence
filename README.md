# South Indian Tourism Analytics & Economic Intelligence

## Project Overview

This project analyzes tourism data across South Indian states and cities
using data cleaning, SQL analysis, and Power BI visualization.

## Technologies Used

- Excel / CSV
- MySQL
- SQL
- Power BI

## Dataset

The dataset contains tourism information including:

- Year
- State
- City
- Domestic Visitors
- Foreign Visitors
- Total Visitors
- Revenue
- Revenue Unit

## Data Cleaning

The dataset was cleaned by:

- Standardizing state and city names
- Removing extra spaces
- Handling missing values
- Removing negative visitor values
- Recalculating Total Visitors
- Standardizing revenue units

## SQL Analysis

The SQL analysis includes:

- Yearly tourism trends
- Year-over-year growth
- City comparison
- Domestic vs Foreign tourism
- Revenue per visitor
- Tourism growth analysis

## Power BI Dashboard

The dashboard contains three pages:

### Page 1 – Executive Overview
- Total Visitors
- Total Revenue
- Growth %
- Yearly visitor trend
- City visitor comparison

### Page 2 – City & Seasonal Intelligence
- City comparison
- Domestic vs Foreign visitors
- Tourism hub analysis

### Page 3 – Economic Risk & Governance
- Tourism growth volatility
- Revenue per visitor
- Missing data monitoring
- Policy recommendations
